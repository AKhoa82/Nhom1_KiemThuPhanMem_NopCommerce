# Dữ liệu kiểm thử Pairwise

Thư mục này dành cho dữ liệu riêng của automation nếu nhóm cần bổ sung sau này.
Hai file nguồn chính thức hiện nằm ở
[`generated-cases.csv`](../../pairwise/test-data/generated-cases.csv) và
[`scenario-mapping.csv`](../../pairwise/test-data/scenario-mapping.csv).

Không tạo bản sao hoặc sửa tay dữ liệu Pairwise trong thư mục này. Bộ đọc dữ
liệu của Trang sẽ đọc trực tiếp hai file nguồn và dùng `CaseId` để tạo test.
